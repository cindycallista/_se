## Working method

1. Define one concrete output before opening a model session.
2. Give the model the relevant files and acceptance criteria.
3. Ask for a small change, then inspect and test it.
4. Record what was generated, changed manually, and verified.
5. Remove private values before sharing prompts or logs.
