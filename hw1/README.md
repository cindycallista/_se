# HW1 — QuickCurl

Student: 楊莉思 (111210555)

Project Page: https://cindycallista.github.io/_se/

A curl-like HTTP client built with Python `urllib`.

```bash
python main.py https://example.com
python main.py -i -L https://example.com
python main.py -X POST -H "Content-Type: application/json" -d '{"name":"Alice"}' https://httpbin.org/post
python main.py -o page.html https://example.com
```

Run `python main.py --help` for all options.
